# React + Vite

Project name: news-explorer-frontend.
Description: A vite project that uses react with full functionality and simulated backend. This site is a news article website. Users can search for news using keywords in a search bar, and then save the articles they find if they have an account. This project contains imported fonts, api responses, and react working in full effect.

**Technologies Used:**

- React
- Vite
- CSS3
- NewsAPI (third-party API)
- JavaScript ES6+

**Features:**

- Keyword-based news search
- User authentication (simulated)
- Save/remove articles functionality
- Responsive design
- Form validation
